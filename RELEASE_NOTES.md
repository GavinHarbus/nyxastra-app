# Release notes

## Mac 1.3.1 (build 17)

Available on the Mac App Store. These release notes cover the Mac update; iPhone/iPad, the earlier macOS DMG and Windows have separate releases.

- Added GPT Image 2.6 Flare and Sunburst through OpenAI.
- Create SVG graphics and GIF animations, with adjustable frame count and timing.
- Access format, size, quality and Complexity directly in the redesigned generation controls.
- Preserve generation settings in downloaded template examples, including Complexity and GIF timing.

GPT Image 2.6 uses the OpenAI provider in this Mac update. GIF generation requires the provider's GIF preview permission. SVG output generates one image without reference images; GIF generation accepts static PNG/JPEG/WebP references.

Templates retain their settings when shared: ordinary raster recipes use v2, SVG recipes v3 and GIF recipes v4. Importing v3/v4 requires a compatible client. Website covers remain static previews.

The existing direct-download DMG and Windows release keep their current model support. Check the App Store version history separately for iPhone and iPad.
